# 使用手册

## 基本操作

### 快捷键

| 操作 | 默认快捷键 | 说明 |
|------|-----------|------|
| 录音 | 按住 右Alt | 按住说话，松开自动识别 |
| 打开设置 | 双击托盘图标 | 打开设置窗口 |
| 启动/停止服务 | 右键菜单 | 暂停或恢复语音输入功能 |

### 状态指示

托盘图标颜色表示当前状态:

- **绿色** - 就绪，可以开始录音
- **红色** - 录音中，正在采集语音
- **蓝色** - 识别中，正在将语音转为文字
- **灰色** - 已停止服务

录音开始和结束时会播放提示音。

## 设置窗口

### 基本设置

- **录音快捷键**: 可选择 右Alt / 右Ctrl / 右Shift / F4 / F8 / F9 / F10
- **触发方式**:
  - 按住说话: 按住按键期间录音，松开后识别
  - 切换模式: 按一下开始录音，再按一下停止并识别
- **识别语言**: 中文 / English / 日本語 / 自动检测
- **开机启动**: 是否随系统自动启动
- **系统通知**: 是否显示系统通知气泡

### 语音识别设置

- **识别模型**: 选择 Whisper 模型大小，影响识别准确度和速度
- **计算精度**: Int8 (最快) / Float16 / Float32 (最准确)
- **麦克风设备**: 选择输入音频设备

### 高级设置

- **VAD 过滤**: 语音活动检测，自动跳过静音部分
- **VAD 灵敏度**: 调节静音检测阈值
- **剪贴板恢复**: 粘贴文字后是否恢复原始剪贴板内容

## 热词管理

热词功能可提升特定词汇的识别准确率，适用于:

- 人名、地名
- 专业术语（医学、法律、技术等）
- 产品名称、品牌名
- 常用缩写

### 添加热词

1. 打开设置窗口
2. 在热词管理区域添加词汇
3. 支持按分类管理（如: 工作、技术文档、日常）

### 热词生效原理

热词通过 Whisper 的 `initial_prompt` 参数注入，模型在识别时会优先匹配提示词中的词汇。

## Emoji 功能

根据说话内容自动在合适位置插入表情符号。

### 密度设置

- **低**: 每段文字最多 1 个 emoji
- **中**: 每段文字最多 2 个 emoji (默认)
- **高**: 每段文字最多 5 个 emoji

### 触发规则

系统内置了丰富的语义规则，例如:
- "开心" / "高兴" -> 对应笑脸 emoji
- "加油" / "努力" -> 对应肌肉 emoji
- "谢谢" / "感谢" -> 对应祈祷 emoji

## 典型使用场景

1. **即时通讯**: 在微信、钉钉等聊天窗口快速输入语音消息
2. **文档写作**: 在 Word、记事本等中语音输入长段文字
3. **邮件撰写**: 在 Outlook 等邮件客户端快速写邮件
4. **代码注释**: 在编辑器中语音输入注释内容

## 注意事项

- 程序需要以 **管理员权限** 运行才能监听全局快捷键
- 录音时请尽量靠近麦克风，减少环境噪音
- 较长的语音（超过 30 秒）识别时间会相应增加
- 首次切换模型时需要重新下载对应模型文件
